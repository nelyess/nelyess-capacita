# Nelyess Capacita

Portal de consulta comercial y administración para Bitel. React + TypeScript + Express.

Lee **GUIA_GITHUB_Y_USO.md** para instalación, acceso, documentos de Drive, respaldo y GitHub.

```bash
npm ci
# Copia .env.example a .env y define ADMIN_PASSWORD antes de entrar al editor.
npm run dev
```

Validación: `npm run lint`, `npm test`, `npm run build`.

Requiere Node.js >=22.12.0 y almacenamiento persistente para `DATA_DIR`.
GitHub Pages por sí solo no ejecuta el servidor ni guarda cambios del editor.
